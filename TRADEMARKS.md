# The Antresol name and logo

The code in this repository is free software (see [LICENSING.md](LICENSING.md)).
**The name "Antresol" and the Antresol logo are not.** They belong to the
project's founding maintainer, and none of the licences in this repository
grants any right to them. The App Store app uses them under a separate
licence from their owner.

The logo is the artwork in these files:

- `web/public/icons/` (`icon.svg`, `icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png`, `apple-touch-icon.png`);
- `web/src/components/logoArt.ts` (the same artwork as SVG markup, used by
  `web/src/components/Logo.tsx`).

The AGPL and the MPL do not apply to that artwork, even though the files sit
in the source tree so that the project builds as it is published.

## What you may do without asking

- Say truthfully that your software works with Antresol, or is based on
  Antresol ("a fork of Antresol", "compatible with Antresol").
- Use the name and the unmodified logo to refer to this project, for example
  in an article, a review, a talk or a package of the unmodified releases.
- Build and run this repository as it is, logo included, for yourself and
  the people you serve it to.

## What needs permission

- Distributing a **modified** version, or a service based on one, under the
  name "Antresol" or with the logo. A fork must use its own name and replace
  the files listed above with its own artwork.
- Using the name or the logo in a way that suggests the project endorses
  you, or as part of your own product, company or domain name.
- Publishing an app under the name "Antresol" in any app store.

Ask in the repository's Discussions.
