# Вспомогательные службы расширений

Некоторым расширениям нужна своя программа рядом с сервером — **вспомогательная служба**.
Например, расширению «Онлайн» нужна служба, которая ищет потоки, а расширению загрузок —
служба, которая проходит проверку сайтов на ботов.

Служба — это ещё один контейнер в вашем `compose.yml`. Расширение находит его само, по имени.

## Подключить службу

1. Откройте страницу настроек расширения. Пока службы нет, там написано «не найдена» и показан
   готовый блок для `compose.yml`.
2. Вставьте этот блок в `compose.yml` под `services:`, рядом с `antresol`. Отступ — два пробела,
   как у `antresol:`.
3. Выполните `docker compose up -d`.

В течение полуминуты страница расширения покажет, что служба найдена. Вводить адрес и
перезапускать сервер не нужно. Отвечают ли службы, видно и в **Настройки → Сервер → Состояние →
Службы расширений**.

Блок выглядит так (имя, образ и порт берите со страницы расширения или из его README):

```yaml
services:
  antresol:
    # ... как было

  имя-службы:
    image: <образ из README расширения>
    restart: unless-stopped
    # сверх этого система остановит службу, а не сервер
    mem_limit: 1536m
```

В блоке нет `ports:`: служба доступна только серверу, снаружи до неё не добраться. В нём есть
предел памяти (`mem_limit`): служба, которая запускает браузер, может расти, пока у машины не
кончится память, и предел заставляет систему остановить эту службу, а не сервер. Если службу
останавливают из-за нехватки памяти, предел можно поднять.

## Где взять блок для каждого расширения

- **Онлайн** — раздел о вспомогательной службе в
  [README расширения](https://github.com/antresol-app/antresol-addon-online#readme).
  Состояние службы: **Настройки → Сервер → Онлайн → Состояние источников**.
- **Загрузки** — README расширения загрузок (в
  [списке репозиториев](https://github.com/antresol-app)). Состояние службы:
  **Настройки → Сервер → Настройки загрузок**.

## Служба уже работает в другом месте

Если такая программа уже запущена у вас в сети, задайте расширению её адрес — на странице его
настроек или в переменной `ANTRESOL_<ID>_…` из README. Заданный адрес главнее: службу рядом
расширение тогда не ищет.

Так же поступите, если сервер запущен не в Docker: имя службы работает только внутри проекта
compose.

## Как это устроено

Каждое расширение объявляет свои службы в манифесте (поле `helpers`: имя, образ, порт). Сервер
показывает их в `GET /api/addons`. Расширение обращается к службе по адресу
`http://<имя-службы>:<порт>` во внутренней сети проекта compose.
