# Все параметры .env

Справочник. Обычно хватает трёх обязательных строк, остальное настраивается в интерфейсе.
После правки `.env` выполните `docker compose up -d`.
Пути в `VAULT_*` — пути внутри контейнера: не вписывайте в них пути хоста.

## Обязательные

| Переменная | Пример | Что делает |
| --- | --- | --- |
| `MEDIA_DIR` | `/srv/media` | Папка с медиа на хосте; `compose.yml` монтирует её в `/media` (чтение и запись). |
| `VAULT_TMDB_KEY` | | Ключ API TMDB для описаний фильмов и сериалов. |
| `TZ` | `Europe/Berlin` | Часовой пояс сервера (телепрограмма, расписания). |

## Папки медиатеки

Имена папок внутри `MEDIA_DIR`, если ваши отличаются от обычных. Мастер первой настройки и
«Настройки → Сервер → Медиатека → Папки на сервере» умеют выбирать их в веб-интерфейсе
вместо этих переменных; выбранные там папки используются вместо переменных, пока их не сбросят.

| Переменная | По умолчанию |
| --- | --- |
| `MOVIES_DIR` | `movies` |
| `SERIES_DIR` | `series` |
| `MUSIC_DIR` | `music` |
| `BOOKS_DIR` | `books` |
| `EBOOKS_DIR` | `books/ebooks` |
| `AUDIOBOOKS_DIR` | `books/audiobooks` |
| `COMICS_DIR` | `books/manga` |

## Перекодирование

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_HWACCEL` | `auto` | `auto`, `qsv`, `vaapi`, `nvenc`, `videotoolbox` или `none`. `auto` при запуске пробует найденные видеокарты коротким пробным кодированием. Контейнеру нужна видеокарта: раскомментируйте строки про неё в `compose.yml`. «Настройки → Сервер → Обработка» переопределяет переменную, как только значение изменено там. |
| `VAULT_HWACCEL_DEVICE` | первое устройство | Узел рендеринга для `vaapi`, когда их несколько, например `/dev/dri/renderD128`. |
| `VAULT_TRANSCODE_DIR` | `/media/tmp/antresol-hls` | Сегменты HLS, эфир каналов и копии для просмотра без сети. Держите папку вне `/config`. Чтобы перенести её через compose, используйте `compose.override.yml`. |
| `VAULT_TRANSCODE_MAX_BYTES` | `21474836480` (20 ГБ) | Предел общего размера сегментов HLS. |
| `VAULT_REPACK_TS` | вкл. | `off` оставляет фильмы `.ts`/`.m2ts` как есть вместо перепаковки в `.mkv`. |

## Сеть

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_PUBLIC_URL` | | Адрес сервера снаружи, например `https://media.example.com`, без `/` в конце: ссылки в письмах и Telegram, вход на Shikimori, внешний адрес для приложений. Обычно его задают в «Настройки → Сервер → Адрес сервера»; переменная главнее. См. [Публичный адрес](public-address.md). |
| `VAULT_TRUSTED_PROXIES` | | Адреса вашего обратного прокси через запятую: только им доверяют заголовки `X-Forwarded-For` и `X-Forwarded-Proto`. |
| `VAULT_TRUSTED_NETS` | | Дополнительные домашние сети через запятую, например Tailscale `100.64.0.0/10`. Если в такой сети вы заходите на сервер по полному имени (Tailscale `host.<tailnet>.ts.net`, `.fritz.box` роутера), впишите это имя и в `VAULT_TRUSTED_HOSTS`, например `*.ts.net`. |
| `VAULT_TRUSTED_HOSTS` | | Дополнительные имена через запятую, по которым дома заходят на сервер, например `media.lan,*.example.org`. [Внешний адрес](public-address.md) сервера, IP-адреса, `localhost` и имена вида `antresol`, `*.local`, `*.lan`, `*.home.arpa` уже считаются домашними; запрос к серверу по любому другому имени считается запросом не из дома, даже с домашнего адреса. |
| `VAULT_SERVER_NAME` | `Antresol` | Имя, которое приложения показывают, когда находят сервер. |
| `VAULT_DISCOVERY` | вкл. | `off` выключает и mDNS, и UDP-запрос, которыми приложения ищут сервер. |
| `VAULT_MDNS` | вкл. | `off` выключает только mDNS. |
| `VAULT_DISCOVERY_PORT` | `8420` | Порт UDP-запроса в контейнере; опубликуйте его как `8420:8420/udp` (`compose.yml` так и делает, на порту хоста `HTTP_PORT`). |
| `VAULT_ANNOUNCE_DIR` | | Папка, общая с mDNS-анонсером (`antresol-mdns` в `compose.yml`, он задаёт `/announce` обоим сервисам): в сети bridge сервер оставляет ему `antresol.local` и поиск приложений. См. [Решение проблем](troubleshooting.md#приложения-не-видят-сервер). |
| `VAULT_ANNOUNCE_PORT` | порт сервера | Только для анонсера: HTTP-порт, опубликованный для сервера на хосте. `compose.yml` берёт его из `HTTP_PORT`. |
| `HTTP_PORT` | `8420` | Только `compose.yml`: порт хоста для веб-интерфейса и приложений (TCP) и для UDP-запроса приложений, сразу для сервера и анонсера. Второму стеку на том же компьютере нужен другой. |

## Внешние сервисы {#external-services}

Открытые сервисы, которые сервер спрашивает о том, что уже есть в медиатеке. Ничего в медиатеку
они не добавляют. У каждого свой переключатель в **Настройки → Сервер → Внешние сервисы**, а мастер
первой настройки показывает их все включёнными. Переключатель действует сразу, без перезапуска.
Переменная из таблицы главнее переключателя, и тогда он показывает, что задано на сервере.

| Сервис | По умолчанию | Что отправляет | Что даёт | Переменная |
| --- | --- | --- | --- | --- |
| Wikidata | вкл. | Номера фильмов и сериалов в TMDB и IMDb, названия книг | Франшизы из разных коллекций TMDB, оценки Rotten Tomatoes, названия книг на других языках | `VAULT_WIKIDATA_BASEURL`: `off`, `on` или свой адрес |
| Рейтинги IMDb | выкл. | Ничего о медиатеке: сервер раз в день скачивает общий файл рейтингов IMDb | Рейтинги IMDb на страницах фильмов и сериалов. Набор данных — только для личного некоммерческого использования | `VAULT_IMDB_RATINGS_URL`: `off`, `on` или адрес зеркала |
| Тексты песен (LRCLIB) | выкл. | Исполнителя, название, альбом и длительность трека | Тексты песен, в том числе синхронные | `VAULT_LRCLIB_URL`: `off`, `on` или адрес своего LRCLIB |
| Заставки и титры (TheIntroDB, IntroDB) | вкл. | Номер фильма или сериала в TMDB/IMDb, сезон и серию | Отметки заставок и титров раньше, чем их найдёт анализ сервера | `VAULT_SEGMENTS_ONLINE`: `on` или `off` |

Рейтинги IMDb и тексты песен выключены, пока вы их не включите: их условия принимаете вы. Набор
данных IMDb разрешён только для личного некоммерческого использования, а у текстов песен есть
авторы. Сервер, на котором ещё ничего не выбрано, один раз показывает об этом разделе уведомление
в **Состоянии**.

## Расширения

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_ADDONS` | вкл. | `off` отключает расширения. |
| `VAULT_ADDONS_DEV` | | Локальные расширения для разработки, по папке на расширение (относительный путь — внутри папки данных). |
| `VAULT_ADDONS_PIN` | | Расширения, закреплённые за релизами из `VAULT_ADDONS_DEV` (`id@версия`, через запятую); ставятся при запуске и заблокированы в админке. |
| `VAULT_ADDONS_ACCEPT_UNSIGNED` | выкл. | Сервер подписывает заголовок профиля, который шлёт расширению, а расширение на свежем addonkit отклоняет неподписанный. `on` разрешает такому расширению принять заголовок без подписи (запасной ход для запросов, сделанных вручную). Расширения на старом addonkit подпись не проверяют. |

Собственные настройки расширения — переменные `ANTRESOL_<ID>_*` (их перечисляет его README).
Расширению может понадобиться вспомогательная служба рядом с сервером: тогда оно находит её по
имени службы в compose, а адрес, заданный в его переменной или на странице его настроек,
главнее ([Вспомогательные службы](addon-services.md)).

## Дополнительно

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_DB_MMAP_BYTES` | `0` (выкл.) | Сколько базы SQLite отображается в память. Чтение ускоряется, но ошибка чтения на диске с `/config` тогда останавливает весь сервер: включайте только на надёжном диске. |
| `VAULT_SOURCE_URL` | этот репозиторий | Ссылка «Исходный код · AGPL» (AGPL §13). Задайте её, когда запускаете изменённый сервер для других; заданная пустой, она скрывает ссылку. |
