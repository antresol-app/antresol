# Конфигурация

Antresol Server читает эти переменные окружения (из `.env` рядом с `compose.yml`).
Большинство настроек вместо этого лежит в веб-интерфейсе: задавайте переменную, только когда она нужна.
Пути в `VAULT_*` — пути внутри контейнера: не вписывайте в них пути хоста.

## Обязательные

| Переменная | Пример | Что делает |
| --- | --- | --- |
| `MEDIA_DIR` | `/srv/media` | Папка с медиа на хосте; `compose.yml` монтирует её в `/media` (чтение и запись). |
| `VAULT_TMDB_KEY` | | Ключ API TMDB для описаний фильмов и сериалов. |
| `TZ` | `Europe/Berlin` | Часовой пояс сервера (телепрограмма, расписания). |

## Папки медиатеки

Имена папок внутри `MEDIA_DIR`, если ваши отличаются от обычных. Мастер первой настройки и
«Настройки → Сервер → Медиатека и языки → Папки на сервере» умеют выбирать их в веб-интерфейсе
вместо этих переменных; выбранные там папки используются вместо переменных, пока их не сбросят.

| Переменная | По умолчанию |
| --- | --- |
| `MOVIES_DIR` | `movies` |
| `SERIES_DIR` | `series` |
| `MUSIC_DIR` | `music` |
| `BOOKS_DIR` | `books` |
| `EBOOKS_DIR` | `books/ebooks` |
| `AUDIOBOOKS_DIR` | `books/audiobooks` |
| `COMICS_DIR` | `books/manga` |

## Перекодирование

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_HWACCEL` | `auto` | `auto`, `qsv`, `vaapi`, `nvenc`, `videotoolbox` или `none`. `auto` при запуске пробует найденные видеокарты коротким пробным кодированием. Контейнеру нужна видеокарта: раскомментируйте строки про неё в `compose.yml`. «Настройки → Сервер → Перекодирование» переопределяет переменную, как только значение изменено там. |
| `VAULT_HWACCEL_DEVICE` | первое устройство | Узел рендеринга для `vaapi`, когда их несколько, например `/dev/dri/renderD128`. |
| `VAULT_TRANSCODE_DIR` | `/media/tmp/antresol-hls` | Сегменты HLS, эфир каналов и копии для просмотра без сети. Держите папку вне `/config`. Чтобы перенести её через compose, используйте `compose.override.yml`. |
| `VAULT_TRANSCODE_MAX_BYTES` | `21474836480` (20 ГБ) | Предел общего размера сегментов HLS. |
| `VAULT_REPACK_TS` | вкл. | `off` оставляет фильмы `.ts`/`.m2ts` как есть вместо перепаковки в `.mkv`. |

## Сеть

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_TRUSTED_PROXIES` | | Адрес вашего обратного прокси: только ему доверяют заголовок `X-Forwarded-For`. |
| `VAULT_TRUSTED_NETS` | | Дополнительные домашние сети через запятую, например Tailscale `100.64.0.0/10`. |
| `VAULT_SERVER_NAME` | `Antresol` | Имя, которое приложения показывают, когда находят сервер. |
| `VAULT_DISCOVERY` | вкл. | `off` выключает и mDNS, и UDP-запрос, которыми приложения ищут сервер. |
| `VAULT_MDNS` | вкл. | `off` выключает только mDNS. |
| `VAULT_DISCOVERY_PORT` | `8420` | Порт UDP-запроса в контейнере; опубликуйте его как `8420:8420/udp` (`compose.yml` так и делает, на порту хоста `HTTP_PORT`). |
| `VAULT_ANNOUNCE_DIR` | | Папка, общая с mDNS-анонсером (`antresol-mdns` в `compose.yml`, он задаёт `/announce` обоим сервисам): в сети bridge сервер оставляет ему `antresol.local` и поиск приложений. См. [install.md](install.md). |
| `VAULT_ANNOUNCE_PORT` | порт сервера | Только для анонсера: HTTP-порт, опубликованный для сервера на хосте. `compose.yml` берёт его из `HTTP_PORT`. |
| `HTTP_PORT` | `8420` | Только `compose.yml`: порт хоста для веб-интерфейса и приложений (TCP) и для UDP-запроса приложений, сразу для сервера и анонсера. Второму стеку на том же компьютере нужен другой. |

## Почта

Почта настраивается в веб-интерфейсе, а не в `.env`: «Настройки → Сервер → Почта и уведомления → Почта для отправки».
Через неё уходят письма-уведомления и книги на Kindle. Подойдёт любой аккаунт SMTP:

| Сервис | Сервер | Порт | Логин | Пароль |
| --- | --- | --- | --- | --- |
| Gmail | `smtp.gmail.com` | 587 | ваш адрес Gmail | [пароль приложения](https://myaccount.google.com/apppasswords) (нужна двухэтапная аутентификация) |
| Resend | `smtp.resend.com` | 465 или 587 | `resend` | ключ API; адрес отправителя должен быть на домене, подтверждённом в Resend |
| Другая почта | в её справке | 587 или 465 | обычно ваш адрес | обычно пароль приложения |

Затем каждый включает нужное в «Настройки → Уведомления» и подтверждает свой адрес
проверочным письмом. Пока не включено, всё выключено.

## Telegram

Уведомления могут идти и в Telegram: рядом с почтой или вместо неё. Те же события,
простым текстом, со ссылкой на фильм или сериал, если задан `VAULT_PUBLIC_URL`. Telegram
настраивается один раз, потом каждому нужно два нажатия.

**Администратор**, один раз: в Telegram откройте [@BotFather](https://t.me/BotFather),
отправьте `/newbot` и придумайте имя. Вставьте присланный токен в «Настройки → Сервер → Почта и
уведомления → Бот Telegram» и нажмите «Проверить»: появится @имя бота. Сервер хранит токен
так же, как пароль SMTP, и больше его не показывает; в лог он не попадает.
«Отключить бота» стирает его.

**Каждый** (профили взрослых), в «Настройки → Уведомления»: «Подключить Telegram» показывает
ссылку. Откройте её в Telegram и нажмите «Запустить»; страница заметит это сама, а бот
подтвердит подключение на языке профиля. «Отключить» там же или блокировка бота в Telegram
прекращает доставку. Детские профили подключить Telegram не могут.

Как это работает:

- Публичный адрес, вебхук и открытый порт не нужны. Сервер сам спрашивает у Telegram новые
  сообщения (long polling), поэтому ему достаточно доступа к `api.telegram.org` по HTTPS, как
  любому домашнему серверу. На сервер приходится один опрос, и только пока задан токен.
- Профиль выбирает каналы: почта, Telegram или оба (переключатель для каждого появляется,
  когда настроены оба). Темы и тихие часы (22:00–08:00 по времени сервера) действуют на оба.
  Каждый канал присылает не больше одной сводки в час на профиль.
- Ограничения Telegram соблюдаются: сообщения идут с интервалом в секунду, а после ответа
  «слишком много запросов» ничего не отправляется, пока не пройдёт `retry_after` от Telegram.
  Чат, заблокировавший бота или удалённый, отключается.
- Токен бота может опрашивать только одна программа. Если на экране сказано, что сообщения
  бота забирает другая программа или у него есть вебхук, заведите для сервера отдельного бота.
- Если заменить токен токеном другого бота, чаты, привязанные к прежнему, отключаются; тот же
  бот, вставленный снова, их сохраняет.

## Расширения

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_ADDONS` | вкл. | `off` отключает расширения. |
| `VAULT_ADDONS_DEV` | | Локальные расширения для разработки, по папке на расширение (относительный путь — внутри папки данных). |
| `VAULT_ADDONS_PIN` | | Расширения, закреплённые за релизами из `VAULT_ADDONS_DEV` (`id@версия`, через запятую); ставятся при запуске и заблокированы в админке. |

Собственные настройки расширения — переменные `ANTRESOL_<ID>_*` (их перечисляет его README).
Расширению может понадобиться вспомогательная служба рядом с сервером: тогда оно находит её по
имени службы в compose, а адрес, заданный в его переменной или на странице его настроек,
главнее ([install.md](install.md#расширения-которым-нужна-вспомогательная-служба)).

## Дополнительно

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VAULT_DB_MMAP_BYTES` | `0` (выкл.) | Сколько базы SQLite отображается в память. Чтение ускоряется, но ошибка чтения на диске с `/config` тогда останавливает весь сервер: включайте только на надёжном диске. |
| `VAULT_SOURCE_URL` | этот репозиторий | Ссылка «Исходный код · AGPL» (AGPL §13). Задайте её, когда запускаете изменённый сервер для других; заданная пустой, она скрывает ссылку. |
