# Ключи API и ИИ-помощники (MCP)

Ключ API даёт ИИ-помощнику — Claude, ChatGPT или любому другому клиенту
[MCP](https://modelcontextprotocol.io) — или своему скрипту работать с
сервером от вашего имени: найти фильм, сказать, что идёт по ТВ, отметить
серию просмотренной, поставить загрузку.

## Создать ключ

**Настройки → Мои настройки → Приложения и устройства → Ключи API и ИИ → Создать ключ.**
Назовите ключ и выберите, что ему можно:

- **Только чтение** — искать в медиатеке, смотреть сведения, календарь серий
  и что идёт по ТВ. Ничего не меняет.
- **Чтение и действия** — ещё отмечать просмотренное и ставить загрузки
  (если на сервере есть расширение для загрузок).
- **Администрирование** (только администраторам) — ещё сканировать
  медиатеку, перезапускать расширения и видеть профили.

Ключ показывается один раз — скопируйте его сразу. На странице видны ваши
ключи и когда каждый использовался, ключ отзывается сразу, а ниже — последние
изменения, сделанные ключами. У ключа никогда не больше прав, чем у
профиля, и ни один ключ не может создавать ключи, менять пароли или
подключать устройства. У детских профилей ключей нет. Профиль без пароля
может пользоваться ключами только из домашней сети.

## Подключить помощника

MCP-сервер находится по адресу `/mcp` на адресе вашего сервера (страница
берёт [внешний адрес](public-address.html) сервера, если он задан). Страница показывает
эти строки с вашим адресом и ключом.

Claude Code:

```sh
claude mcp add --transport http antresol https://media.example.org/mcp \
  --header "Authorization: Bearer ВАШ_КЛЮЧ"
```

Claude Desktop (`claude_desktop_config.json`, нужен Node.js):

```json
{ "mcpServers": { "antresol": { "command": "npx",
  "args": ["-y", "mcp-remote", "https://media.example.org/mcp",
           "--header", "Authorization: Bearer ВАШ_КЛЮЧ"] } } }
```

Любой другой клиент: транспорт Streamable HTTP по адресу
`https://media.example.org/mcp` с заголовком
`Authorization: Bearer ВАШ_КЛЮЧ`.

Инструменты: `search_library`, `get_item`, `continue_watching`,
`recently_added`, `tv_now`, `upcoming_episodes`, `server_status`,
`discover_titles`; с «Чтением и действиями» ещё `set_watched`,
`download_title`; с «Администрированием» ещё `scan_library`,
`restart_addon`, `list_profiles`. Ни один инструмент ничего не удаляет.

## API

Тот же ключ работает с HTTP API сервера: отправляйте
`Authorization: Bearer ВАШ_КЛЮЧ` на маршруты `/api/…`, которыми пользуется
веб-приложение. Ключ «Только чтение» допускает только запросы `GET`. Ключ
может сделать около 120 запросов в минуту (дальше — `429` с `Retry-After`).
